# Changelog

## 0.2.0 — 2026-10-28

- Changed the default from a required selection pause to advice followed by execution in the same turn with current session settings.
- Retained explicit manual-wait mode, advice-only answers, required permissions, and critical-input boundaries.
- Documented why an instruction-only skill cannot promise one-minute wake-up or automatic model switching; no daemon, timer, or model configuration changes added.
- Updated both READMEs, project snippets, installation checks, trial package, illustrative assets, and 18 public reference cases.
- Kept the existing repository and skill identity; documented how to update copied installations and conflicting AGENTS.md rules.

## 0.1.0 — 2026-10-23

- Initial instruction-only public package, separate from the original personal skill.
- Three task classes, a short recommendation, one selection pause, accepted-continuation handling, and an explicit no-pause option.
- Dated model guide grounded in official OpenAI documentation.
- English and Simplified Chinese README, installation/removal guide, optional project trigger snippet, 12 public behavior cases, and a 30-second illustrative walkthrough.
- No claimed percentage savings or independent accuracy benchmark. See validation status for checks and remaining limits.
- Prepared early-preview release notes and a directly downloadable, project-scoped friend trial package with Chinese quick-start instructions.

# 直接试用：不需要终端

[下载朋友试用包](../downloads/codex-model-preflight-v0.1.0-friends.zip)。如果 GitHub 显示文件页，点击下载原始文件，再完整解压。

1. 用你平时的 Codex 打开包内的 **Codex试用项目** 文件夹，并新开聊天。选择这个子文件夹，而不是压缩包或上一级目录。
2. 发送：`请根据订单样例.csv，按试用任务.txt完成任务。`
3. 观察是否先给出模型、推理档位和速度建议，并暂停一次。你可以手动选择后回复“继续”，也可直接说“按当前设置继续”。
4. 完成后发送：`把试用说明的标题改成“试用结果”。` 这个小改通常不应重新分档。

没有提示时，先重开聊天，必要时重启 Codex；再试：

```text
请用 $codex-model-preflight，先为这个任务给出配置建议。
```

自动匹配取决于客户端和模型。手动调用成功不代表自动触发也已验证，请分别反馈。

本包包含虚构数据、项目范围的技能和短触发规则、Word/TXT 说明、文字流程演示和自愿反馈表。它不改全局配置，也不自动上传反馈。退出时关闭该试用项目；需要清理时只删除你解压出的文件夹。

第一次试用主要看三件事：能否独立开始、建议是否易懂、是否有多余暂停。它尚未证明固定额度节省。

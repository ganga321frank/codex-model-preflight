# v0.2.0 不再因选档等待而停工

更新日期为2026年10月28日，继续使用原仓库与同名 Skill，v0.1.0 发布记录保留供回退。本次仍为试用预览版。

默认行为改为：简短给出建议后，同一轮按当前会话配置执行原任务，不再要求回复“继续”。明确说“先等我选档”仍暂停；单独询问模型建议时只回答建议。必要授权和关键资料缺失不受这项默认行为影响。

本包不新增一分钟计时、后台监听或自动模型切换，不修改全局模型配置。真正的计时后启动需要宿主集成；详见[设计判断](interaction.md)。默认当前配置可能不同于建议，不能声称已经按建议模型执行或因此节省额度。

升级时替换现有Skill并核对旧AGENTS.md选档段落，避免旧的强制暂停规则覆盖新行为。参考[升级步骤](install.md#upgrading-from-v010)、[触发规则](agents-snippet.md)与[验证说明](validation.md)。旧版已经发布的图片和帖子描述可能仍讲“回复继续”；新版说明和演示应以本次更新为准。
